# Artificial Intelligence

This folder contains all assignments, projects, and deliverables completed for the **Artificial Intelligence (EN.605.645)** course, part of the Johns Hopkins Engineering for Professionals (EP) program.

---

## Course Overview

This course provides a foundational exploration of artificial intelligence, covering symbolic reasoning, optimization techniques, and machine learning approaches. It emphasizes the integration of these methods under the framework of **Hybrid AI**, recognizing that real-world AI systems benefit from combining multiple paradigms.

Importantly, **all algorithms and functions in this course were implemented from scratch** — no black-box libraries or prebuilt machine learning packages were used — ensuring a deep understanding of algorithmic mechanics and underlying principles.

---

## Learning Objectives

By the end of this course, I was able to:
- Identify core AI algorithm families and explain their distinguishing characteristics.
- Implement foundational AI algorithms in Python for reasoning, optimization, and pattern recognition tasks.
- Evaluate and compare algorithm performance on real-world problems.
- Apply Hybrid AI techniques by combining symbolic and numeric approaches.
- Understand the ethical and societal implications of developing and deploying AI systems.
