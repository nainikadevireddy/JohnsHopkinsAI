### Task 2: Requirements Analysis

#### Task 2.1: Based on the elicited information from the collective posts, list at least five functional requirements and five non-functional requirements for the "SecureBank" fraud detection system.

#### Task 2.2: Analyze and prioritize these requirements. Explain the criteria you used for prioritization.

---

#### Functional Requirements

* The system should precisely detect fraudulent transactions in real-time.
* The system should generate alerts for flagged fraudulent transactions for the fraud detection team and the client.
* The system should integrate with SecureBank's existing databases of transaction data and client information, and integrate with the existing IT infrastructure 
* The system should generate metric repots on the system's performance, documenting false positives, false negatives and system performance, precision and recall. 
* The system should facilitate the review process for flagged transactions until the case is resolved.


#### Non-Functional Requirements

* The model must identify fraudulent transactions with precision above or at 40%, and recall above or at 85%.
* The system must be scalable to the numerous transactions concurred by the hundreds of thousands of SecureBank clients.
* The system should provide a user-friendly interface for customers to confirm flagged transactions.
* The system should operate effectively, efficiently, and ethically while complying with regulatory requirements and internal policies. 
* The system should document the algorithmic process and decision-making process for potential audit review.


#### Prioritization
To prioritize the requirements, there are some key players that should be considered: user impact, feasibility, business impact and compliance. User impact involves the ease of using the system from either the client or fraud detection team's perspective. Feasibility is how doable a certain task is given certain technical and time restraints. Business impact involves the requirements that directly reduce fraudulent transactions and improve profitability for SecureBank. Compliance involves ensuring the system is compliant with financial, legal and security regulations. Of these four criteria, business impact and feasibility may have the highest priority. The business impact directly illustrates the goals of the project, while the feasibility outlines the technical and physical scope of the project.
