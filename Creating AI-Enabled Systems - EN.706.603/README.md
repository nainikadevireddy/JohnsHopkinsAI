# Creating AI-Enabled Systems

This repository contains all major assignments, projects, and deliverables completed for the **Creating AI-Enabled Systems (EN.705.603)** course, part of the Johns Hopkins Engineering for Professionals (EP) program.

---

## Course Overview

This course explores the system engineering perspective required to build robust AI-enabled solutions. It covers the **end-to-end lifecycle** of AI systems, including problem decomposition, data engineering, model development, system design, deployment, monitoring, and continuous improvement. Students gain hands-on experience across domains such as tabular data, computer vision, natural language processing, and physical systems.

---

## Learning Objectives

By the end of this course, I was able to:
- Apply the full lifecycle of developing, deploying, and operating AI systems.
- Decompose complex problems to identify appropriate AI solutions.
- Engineer and manage data pipelines to support AI system needs.
- Select and implement suitable AI models and architectures.
- Evaluate models with appropriate metrics, including fairness and bias measures.
- Design effective deployment strategies with monitoring and retraining components.
- Package and share projects using tools like GitHub and Docker.
